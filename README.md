# A21-projet

## Description

A21-projet est une application développée dans le cadre d'un projet académique pour le BUT Informatique. Ce projet vise à faciliter la gestion d'événements en proposant des fonctionnalités pour créer, organiser et suivre des événements. Il met en avant des compétences en développement logiciel, gestion de bases de données et intégration d'outils modernes.

Ce projet illustre des compétences en développement avec le framework .NET, l'intégration de bases de données SQLite, ainsi que des pratiques collaboratives de développement logiciel via GitLab.

## Fonctionnalités

- Création et gestion d'événements.
- Intégration d'une base de données SQLite pour la persistance des données.
- Interface utilisateur intuitive pour gérer les détails des événements.
- Mise en œuvre des bonnes pratiques de développement logiciel.
- Utilisation de pipelines CI/CD pour l'intégration et le déploiement continus.

## Technologies utilisées

- **Langage de programmation** : C#
- **Framework** : .NET Framework 4.7.2
- **Base de données** : SQLite
- **Gestion de version** : GitLab
- **Environnement de développement** : Visual Studio
